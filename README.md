# PixiJS Survival Game 🎮
Мінімалістична 2D гра в жанрі "Survival / Clicker", розроблена з використанням **Pixi.js v8**.

## Функціонал
У грі реалізовано:
* **Геймплей:**
    * Система рівнів (конфігурація в JSON) - src/assets/data/levels.json.
    * Динамічна складність (зміна швидкості та кількості ворогів).
    * Знищення ворогів кліком.
    * Умови перемоги (всі знищені) та поразки (час вийшов).
* **Механіки:**
    * Таймер та лічильники.
    * **Бустер:** Додатковий час (+10 сек), доступний 1 раз на рівень.
    * **Пауза:** Зупинка логіки гри.
    * **Рейтинг:** Система зірок (1-3) залежно від швидкості проходження.
* **Інтерфейс:** Меню, HUD, Екран результатів.
* **Аудіо:** Фонова музика, звукові ефекти, кнопка Mute.

## Технології
* **Core:** [Pixi.js 8](https://pixijs.com/)
* **Language:** TypeScript 5+
* **Bundler:** Webpack 5
* **Audio:** @pixi/sound

## Інструкція із запуску
Для запуску проєкту необхідно мати встановлений **Node.js**.

### 1. Клонування репозиторію
```
git clone git@github.com:RomanovAleksander/pixi-game.git
cd pixi-game
```
### 2. Встановлення залежностей
Встановити всі необхідні пакети з `package.json`
```
npm install
```
### 3. Запуск у режимі розробки
Ця команда запустить локальний сервер. Гра відкриється за адресою http://localhost:8080
```
npm start
```
### 4. Збірка для продакшену
Створює оптимізовану, мініфіковану версію гри у папці dist
```
npm run build
```

## Структура проекту
```
src/
├── assets/ - cтатичні файли: зображення, звуки, JSON-конфіги рівнів
├── game/ - ігрова логіка (Enemy, LevelManager, SoundManager)
├── scenes/ - логіка відображення сцен (Menu, Game, Result)
├── ui/ - елементи інтерфейсу (HUD, Button)
├── types.ts - TypeScript інтерфейси та типи
├── SceneManager.ts - менеджер сцен
└── index.ts - точка входу: ініціалізація PixiJS та завантаження ресурсів
```
